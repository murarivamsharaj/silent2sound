# Project: Silent2Sound
An application that takes silent video, uses AI to analyze scenes/actions, and layers generated ambient sound, foley, and lip-synced audio.

## Rules
- Backend: Java 21, Spring Boot 3, Maven.
- Frontend: React, Vite, TypeScript, Tailwind CSS.
- Database: PostgreSQL.
- Crucial: The developer is a Java engineer. Do NOT write Python scripts. All AI inference is handled via external REST APIs. Video mixing is done using local FFmpeg.
